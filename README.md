# HTTP Status Code Checker — Chrome Extension

Fast, privacy-friendly Chrome Extension to check **real HTTP status codes** for up to 200 URLs at once. Full redirect chains, response times, export.

**Author:** Hamza Ghanchi | GitHub: https://github.com/hamzagofficial

![Version](https://img.shields.io/badge/version-1.1.0-blue)
![Manifest V3](https://img.shields.io/badge/Manifest-V3-green)
![License](https://img.shields.io/badge/license-MIT-brightgreen)

## Features
- ✅ Real codes: 200, 201, 204, 301, 302, 303, 304, 307, 308, 404, 410, 429, 500, 502, 503
- 🔗 Full redirect chain with Location header
- ⏱️ Response time + hop count
- 📊 Filter 2xx / 3xx / 4xx / 5xx
- 📤 Export CSV / JSON, Import .txt/.csv
- 🔒 No tracking, 100% local

## Install
1. chrome://extensions → Developer Mode ON
2. Load unpacked → select this folder
3. Pin extension
